# Блок оплаты в шапке таблицы — инструкция для программиста

Блок стоит в шапке листа Payments: тариф и цифры в J1:J3, кнопка в K1, подписи в K2:L3, ссылки на папку и инструкцию в M2:M3.

Бот пишет только в таблицу Settings выше, в столбец Value. Шапка считается формулами сама.
Значение ищется по названию в столбце Setting: названия не менять (уточнение в скобках дописать можно), строки двигать можно.

## Что писать

- Plan — код тарифа латиницей: free, start, growth, scale.
- Docs limit (this month) — лимит документов в текущем месяце вместе с докупленными пакетами. У free — 30.
- Docs used (this month) — сколько документов учтено в текущем месяце. Дубли и файлы без платежа не считаются, многостраничный PDF — по страницам. Если больше лимита, шапка покажет 0.
- Paid from — первый день оплаченного срока. Дата (число), не текст. У free пусто.
- Paid until — последний оплаченный день, включительно. Дата (число), не текст. У free пусто.
- Payment link — https://nota.axiomco.io/pay/<код>. Код случайный и постоянный для таблицы, без почты и ID; создаёт сервер при подключении Google.
- Language — язык таблицы: en, ru или id.

## Когда писать

- Подключение Google — все 7 значений: free, 30, 0, пусто, пусто, ссылка, язык.
- Каждый учтённый документ — Docs used + 1.
- Оплата (сигнал платёжного сервиса на сервер) — Plan, Docs limit, Paid from, Paid until. Продление: новый срок с дня после Paid until. Смена тарифа посреди срока — правило ещё не утверждено.
- Начало каждого месяца внутри оплаченного срока (тарифы на 3 и 6 месяцев) — Docs used = 0, Docs limit = лимит тарифа.
- Пакет +50 документов — Docs limit + 50. Срок действия пакета ещё не утверждён (предложение: до конца оплаченного срока).

## Что считают формулы — не трогать

- Осталось документов = Docs limit − Docs used, не меньше 0. Осталось дней = Paid until − сегодня + 1; 0 — срок истёк.
- Полоски из 4 блоков, подписи и название тарифа — на языке Language. Кнопка «Payment ➚» ведёт на Payment link.
- Цвет: кнопка зелёная; оранжевая — осталось ≤ 10% документов или ≤ 3 дней; красная — документы кончились или срок истёк.
- Новые таблицы создавать копированием шаблона — формулы и правила цвета переносятся как есть. Исходники: репозиторий axiom-site, папка founder/billing-block.

Формулы и правила цвета: `formulas.py` → `f.json`, запрос для Sheets API: `build-request.py`.
