# Прототипы сайта Axiom Consulting (26.11.2026)

Опубликованы артефактом: https://claude.ai/artifact/BMLK5snynmWWwqo5KJmAhD (закрытая ссылка).

- `index.html` — обзор: выводы исследования, позиционирование, карта сайта, структура страниц, книга цифр, вопросы основателю.
- `a.html` — главная, вариант A «Тёплая редакционная ясность» (из anthropic.com), `audit.html` — страница услуги «Аудит финансовой модели» в том же стиле.
- `b.html` — главная, вариант B «Прозрачный продукт» (структура onlytraffic.com, Gridlines, Ramp).
- `c.html` — главная, вариант C «Тихий частный банк» (Pictet, Centerview, Evercore).
- `content.md` — единый источник текстов и цифр для всех вариантов (заглушки ⟦…⟧ — команда, отзывы, цены, контакты).
- `build-spec.md` — технические правила прототипов.

Это прототипы, не сайт: после выбора варианта сайт собирается на Astro в корне репозитория.
