## Первое сообщение после /start

Текст утверждён основателем 15.11 (правки основателя: «папку с документами», «на что обратить внимание», «любой документ»).

Кто нажимает Start: человек с сайта, которому обещали «пришлите архив — получите отчёт». У одного архив готов (сидит за компьютером), у другого под рукой только телефон: «соберу завтра» — и бот забыт. Поэтому в одном сообщении: что это за продукт (одной строкой), и два пути, которые человек выбирает по своей ситуации, а не гадает, что лучше:
- 📦 **есть архив** — обещанный на сайте отчёт, дальше бот ведёт к Google;
- 📊 **архива под рукой нет** — подключить Google и переслать любой чек: через минуту строка в своей таблице, архив — когда удобно.
Внизу — бесплатно и без карты, условия, и что доступ только к созданным таблице и папкам: человеку должно быть спокойно.

## Архив: получен → (остановлен) → разобран

Тексты основателя (15.11) с правками: глаголы без рода («Архив получен»), «{N} из {M}» в итоге разбора, строка про бесплатный лимит и подключение Google — по условию. В ⟪⟫ — показывать только при условии.

**Архив получен**
```
📦 Архив получен: {F} файлов.
⏳ Разберу примерно за {xx} мин и пришлю отчёт.

[■ Остановить разбор]
```
Про бесплатный лимит здесь не пишем (основатель, 15.11): бот разбирает весь архив, о тарифе говорим после отчёта.

**Разбор остановлен** (кнопка «Остановить разбор»)
```
■ Разбор архива остановлен.
Разобрано {K} из {F} файлов. Формирую отчёт по ним.
```
{F} — то же число, что в «Архив получен» (в примере были 11 и 20 — должно совпадать).

**Архив разобран** (подпись к отчёту — чистая, её пересылают; утверждено основателем 15.11)
```
📦 Архив разобран: {N} из {M} документов

💰 Расходы: 128,40 млн IDR
🟠 Стоит проверить: 7 · 5,6 млн

Подготовлено в Nota · @NotaGetBot

[Открыть таблицу]  [Поделиться отчётом]
```

**Сразу следом — одно действие за раз** (основатель, 15.11: не ставить человека перед выбором «Google или тариф»). Сначала Google: человек видит свою таблицу с записанными документами, а про тариф ему скажет сообщение после подключения Google (там уже есть условная строка «Бесплатные 30 закончились…» и кнопка «Выбрать тариф»).

Если Google не подключён (неважно, кончился лимит или нет):
```
Подключите Google — запишу документы в вашу таблицу: суммы, даты, категории и ссылки на оригиналы. Доступ у меня будет только к таблице и двум папкам, которые я создам.

[📊 Подключить Google]
```

Бесплатный лимит кончился — универсальное сообщение (основатель, 15.11: чем меньше видов, тем лучше). Верно и когда в архиве остались неразобранные документы, и когда их нет; подходит и для момента, когда кончился лимит на документах по одному.
```
Бесплатные 30 документов закончились. Выберите тариф — и я продолжу записывать документы.

[💳 Выбрать тариф]
```
Без «чтобы я продолжил» — бот без рода.

Если Google подключён и лимит не кончился — следом ничего не отправлять.

Правки к тексту основателя: «Чтобы я записал» → без рода; «все документы» убрано (при исчерпанном лимите в таблицу попадут не все); «к этой таблице» → «к таблице» (до подключения её ещё нет); «и т.д.» убрано; «2 папкам которые» → «двум папкам, которые». ## Ответ на кнопку «Как собрать архив»

Текст основателя (15.11) с правками: заголовок = название кнопки (и без «за прошлые месяцы» — основатель убрал это в сообщении после Google); «документы» вместо «чеки и счета», как везде; Telegram и WhatsApp в одном формате; «пачкой» → «сразу несколько».
```
📦 Как собрать архив

Соберите документы в одну папку или выгрузите рабочий чат — и пришлите сюда (до 50 МБ).

• Telegram: Telegram Desktop → чат → ⋮ → «Экспорт истории чата» → оставьте фото и файлы.
• WhatsApp: чат → «Экспорт чата» → «С медиафайлами» → отправьте в Nota.

Папку на macOS можно просто перетащить сюда, на Windows сначала сожмите её в ZIP.

Или перешлите документы сюда — можно сразу несколько.
```
Проверить: «до 50 МБ» — стандартный Bot API даёт боту скачать файл только до 20 МБ; 50 МБ возможно, если бот работает через свой сервер Bot API. Если реальный предел другой — поправить число; если архив больше — дописать «Больше — разбейте на несколько архивов». Перетаскивание папки на macOS — проверить в приложении Telegram для Mac.

## Подсказка «Что делать с дублями?»

Текст основателя (15.11) с правками: «дубли», как на сайте; какую строку с чем сверять — по колонкам таблицы (Check = DBL, Match → ID оригинала); действие словами «поставьте»; названия колонок как в таблице (Status, Check).
```
💡 Что делать с дублями?
Сравните строку с пометкой DBL и строку, на которую она ссылается в колонке Match:
• Это дубль → поставьте Status = Rejected: строка станет бледной и не войдёт в итоги.
• Не дубль → поставьте Check = OK: строка останется в учёте.
```

## Валюта итогов

## Проверить в боте
- Сколько бот хранит неоплаченный остаток архива, если тариф так и не выбрали (на сайте для случая без Google — 10 дней)? И как это сочетается с «Документы — лишь на время обработки» в блоке «Ваши данные» (аудит, вопрос 17) — выровнять завтра.
- Вторая папка — Proof of Payment (из текстов основателя): на сайте сейчас «в папку» (шаг 3) и «к таблице и двум папкам» («Ваши данные») — выровнять завтра (аудит, вопрос 18).
