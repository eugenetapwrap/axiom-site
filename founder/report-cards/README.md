## Правила для реальных данных (17.11)
- Изменения у категорий — в единицах валюты к прошлому периоду: «Ремонт +1,05», «Расходники −3,50» (вместо процентов и «×N»; панель не понимала «×17 чего?»). Цветом — только самый большой рост (оранжевый) и самое большое снижение (зелёный), остальные серые; изменения меньше 0,01 не показываем; от 1 000 единиц — без копеек («+3 890»).
- Общий итог к прошлому периоду: до +200% — «+73%», от +200% — «×N», не больше «×99+»; рядом сумма прошлого периода.
- Нет данных за прошлый период — ничего не пишем (ни строки сравнения, ни изменений у категорий): фраза «за сентябрь данных нет» путает (основатель, 17.11).
- Среднее за день: плановый отчёт (неделя — в понедельник, месяц — 1-го) делит на все дни периода; отчёт по запросу — на дни до сегодняшнего включительно (4-й день недели — на 4). Первый период клиента — считать с первого документа.
- Первый период клиента: к подписи «· данные с 17 окт».
- Пустые показатели — только серый текст, без «0»: «Документов для проверки нет», «Дублей не найдено», в архиве «Рукописных нет».
- Высота карточки — по содержимому, но не меньше 1080 (квадрат); полные отчёты — 1080 × 1350. Подпись внизу всегда с отступом от содержимого.
- Итог: шрифт по длине числа (до 4 цифр — 120 px, 5 — 100, 6 — 84, больше — 72), без переноса; суммы в плитках тоже уменьшаются. Проценты в колонке в сумме 100 (наибольшие остатки), доля меньше 0,5% — «<1%», сумма меньше 0,005 единицы — «<0,01».
- Списки: не больше 8 строк (архив — 7); лишнее — «Остальные N». Без категории — «Без категории» (оранжевая точка); без поставщика — «Не указан» обычным цветом (это проблема, а не мелочь), в платежах — «Поставщик не указан».
- Длинные названия обрезаются многоточием; в шапке архива — имя аккаунта и файла тоже.
- Нет расходов за период (всё отклонено или дубли) — карточки нет, вместо неё сообщение «нет расходов».
- Подписи периода: «9–15 ноя 2026», «30 ноя – 6 дек 2026», «28 дек 2026 – 3 янв 2027».
- Документы со статусом Rejected в расходы не входят; в архиве — «Не вошли в расчёт: N отклонённых документов»; если таких нет, строки нет.
- Вне продукта (основатель, 17.11): бюджет и план-факт, разбивка по объектам (пока), кнопки под картинкой (в архиве и таблице есть Review и DBL).

## Языки и валюты
- Языки: ru, en, id — все тексты карточки в словаре `T`; категории — `CAT_NAMES`; месяцы и дни недели свои.
- Числа: ru «1 230,45», en «1,230.45», id «1.230,45».
- Валюты (`CUR`): IDR, VND — в миллионах («млн» / «M» / «jt»); RUB, THB — в тысячах («тыс.» / «K» / «rb»); USD, EUR, SGD — как есть, с копейками, без единицы. Плашка в шапке — код валюты. Полные суммы платежей — без дробной части для IDR, VND, RUB, THB и с двумя знаками для USD, EUR, SGD.
- Проверено 17.11 на матрице: ru-IDR, en-USD, id-IDR, ru-RUB, en-EUR, id-VND, ru-THB — без переполнений и наложений; стресс-набор (20 случаев: огромные суммы, один документ, только дубли, без категорий и поставщиков, длинные имена, переходы через месяц и год, февраль, первый месяц, отчёт по запросу) — итог совпадает со списками, проценты дают 100.

## Генератор
`generator/cards.py` (v2) — собирает архив, неделю и месяц из строк листа Payments по шаблонам выше:
- `archive_card(rows, account, file_name, received_date, loc='ru', cur='IDR')`;
- `period_card(rows, start, end, 'week'|'month', account, loc, cur, prev_rows=None, report_date=None, client_start=None)` — `prev_rows=None` значит данных за прошлый период нет; `report_date` — день отправки (для среднего за день); `client_start` — первый документ клиента.

Строка — dict: date, amount (в валюте отчёта), payee, check (OK / Review / DBL), status (Rejected — не входит), cat (ключ из таблицы: Materials, Supplies…), type (Hand — рукописный). Возвращает HTML или None (нет расходов). Рендер — Playwright, ширина 1080; высоту считать по правилу выше.
