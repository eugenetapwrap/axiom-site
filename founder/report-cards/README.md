## Правила для реальных данных (17.11)
- Проценты к прошлому периоду (у категорий и у общего итога): до +200% — «+18%», «−29%»; от +200% — «×N» («×17»). Если в прошлом периоде категории не было — процент не показываем. Нет данных за прошлый период — нет ни строки сравнения, ни процентов.
- Цветом — только самый большой рост (оранжевый) и самое большое снижение (зелёный), остальные проценты серые.
- Пустые показатели — серый «0»: «дублей не найдено», «документов для проверки нет» (одинаково во всех отчётах); в архиве ещё «рукописных нет».
- Высота карточки — по содержимому, но не меньше 1080 (квадрат); полные отчёты — 1080 × 1350. Подпись внизу всегда с отступом от содержимого.
- Списки: не больше 8 строк (архив — 7); лишнее — «Остальные N». Без категории — строка «Без категории» (оранжевая точка); без поставщика — серая строка «Не указан», в платежах — «Поставщик не указан».
- Длинные названия обрезаются многоточием (колонки не растягиваются под текст).
- Документы со статусом Rejected в расходы не входят; в архиве — «Не вошли в расчёт: N отклонённых документов»; если таких нет, строки нет.

## Генератор
`generator/cards.py` — собирает архив, неделю и месяц из строк листа Payments по шаблонам выше: `archive_card(rows, account, file_name, received_date)`, `period_card(rows, start, end, 'week'|'month', account, prev_rows, prev_label)`. Строка — dict: date, amount, payee, check (OK / Review / DBL), status, cat (русское название), type (Hand = рукописный). Перевод категорий из таблицы — словарь `CAT` (проверить с названиями в боте). Рендер — Playwright, ширина 1080; высоту считать по правилу выше.
