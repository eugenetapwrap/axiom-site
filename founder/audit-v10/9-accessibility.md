# Аудит доступности: лендинг Nota (v10)

**Стандарт:** WCAG 2.1 AA, по скиллу design:accessibility-review | **Дата:** 15.11.2026

**Как проверял.** Собранная страница `nota/dist/index.html`, локальный сервер на порту 4420, Playwright с Chromium. Основные экраны: 390×844 (iPhone 13) и 1440×900. Дополнительно: ширины 280, 320, 344, 360 и 375 px, телефон боком (844×390), 1440×900 при масштабе 200% (720×450) и 1280×800 при 200% (640 px). Контраст посчитан по вычисленным цветам каждого текстового узла (512 на телефоне, 546 на компьютере) с учётом полупрозрачных фонов; заодно проверены состояния «3 месяца» в ценах, вторая вкладка таблицы и включённая липкая кнопка. Клавиатура: полный проход Tab и Shift+Tab на обоих экранах, на каждой остановке замерены обводка фокуса, её контраст к фону и то, не закрыт ли элемент шапкой или липкой кнопкой. Вместо читалки смотрел дерево доступности Chromium через CDP; живые VoiceOver и NVDA не запускал. Все предложенные правки CSS проверены подмешиванием стиля в страницу, файлы сайта не менялись. Скрипты и снимки лежат в `/tmp/claude-0/-home-user-axiom-site/de8fefbc-96f8-5634-8943-ac0f3a366fca/scratchpad/audit2/a11y-work/`.

Про размер целей: скилл требует 44×44 px (критерий 2.5.5). В WCAG 2.1 это уровень AAA, а на уровне AA в WCAG 2.2 действует 2.5.8 с порогом 24 px. Ниже указаны оба порога.

Жёлтые заглушки «Черновик», «Имя», «ссылка» в находки не входят.

## Итог

**Находок:** 17 | **Высокая важность:** 3 | **Средняя:** 5 | **Низкая:** 9

Контраст текста почти везде в норме: серый на бежевом даёт 5,1–5,5:1, текст в подвале 5,9–11,3:1. Не проходят только кнопки «Начать бесплатно» в ценах. Главные проблемы другие:
- на телефонах уже 375 px обрезается правый край шага 2;
- на тёмных блоках фокус почти не виден, а на «Обсудить» не виден совсем;
- на телефоне липкая кнопка закрывает элемент, на котором стоит фокус.

Все три высокие находки чинятся тремя правками CSS.

### Код к правкам

**А. Лента отзывов: `aria-disabled` вместо `disabled`** (Landing.astro, функция `sync` и обработчик клика, строки 310–315):

```js
function sync() {
  var max = t.scrollWidth - t.clientWidth - 2;
  btns[0].setAttribute('aria-disabled', t.scrollLeft <= 2);
  btns[1].setAttribute('aria-disabled', t.scrollLeft >= max);
  document.querySelector('.rv-nav').hidden = max <= 0;
}
btns.forEach(function (b) {
  b.addEventListener('click', function () {
    if (b.getAttribute('aria-disabled') === 'true') return;
    t.scrollBy({ left: step() * Number(b.dataset.dir), behavior: calm ? 'auto' : 'smooth' });
  });
});
```

**Б. Вкладки: Home и End** (Landing.astro:156–160, вместо текущего обработчика `keydown`):

```js
t.addEventListener('keydown', function (e) {
  var n;
  if (e.key === 'ArrowRight') n = (i + 1) % tabs.length;
  else if (e.key === 'ArrowLeft') n = (i + tabs.length - 1) % tabs.length;
  else if (e.key === 'Home') n = 0;
  else if (e.key === 'End') n = tabs.length - 1;
  else return;
  e.preventDefault(); show(n); tabs[n].focus();
});
```

**В. Три строки CSS, которые закрывают все высокие находки:**

```css
/* 1. global.css:817 — убрать white-space: nowrap у .sched dd */
@media (max-width: 640px) { .sched { padding: 16px 18px 6px; } .sched dl { font-size: 15px; } .sched dd { padding-left: 14px; } }

/* 3. в блок @media (max-width: 899px) у .sticky-cta */
@media (max-width: 899px) { html { scroll-padding-bottom: 96px; } }
```

### Что чинить первым

1. **Правки из пункта В** (около 10 минут). Они закрывают обрезанный край на телефонах шириной 360 px, невидимый фокус на тёмных блоках и фокус под липкой кнопкой.
2. **Alt примера отчёта на компьютере и кнопки цен 19 px.** Первое возвращает читалке главную картинку страницы, второе — единственный провал по контрасту текста.
3. **Лента через `aria-disabled`, заголовки h3 у тарифов, «+» в вопросах.** Это убирает потерю фокуса и одинаковые ссылки для читалки.

### Остальное

- **prefers-reduced-motion.** Плавная прокрутка страницы отключается (`scroll-behavior: auto`), анимации кнопок и выезд липкой кнопки отключены, лента отзывов листается сразу, без анимации (проверено: через 60 мс уже в конечной точке). Запущенных анимаций на странице нет ни в одном режиме. Остались только затухания тени и прозрачности за 0,15 с; это не движение.
- **Масштаб 200%** (1440×900 → 720×450). Горизонтальной прокрутки нет, вёрстка перестраивается в одну колонку, текст не обрезается. Масштабировать пальцами можно: в `meta viewport` нет `maximum-scale` и `user-scalable=no`. Что пропадает при увеличении — см. находки 8 и 16.
- **Интервалы в тексте (1.4.12)** на 1440 px: ничего не обрезается и не налезает. На телефоне проблема одна, та же, что в находке 1.
- **Липкая кнопка на телефоне** не перекрывает финальную кнопку и сноску в подвале: у финала она прячется. Появляется она, только когда на экране нет других оранжевых кнопок.
- **Разметка.** `lang="ru"`, заголовок страницы осмысленный. Повторяющихся id нет, все `aria-controls`, `aria-labelledby` и якорные ссылки ведут на существующие элементы. Есть ориентиры header, main, footer и два nav с подписями.
- **Нет ничего, что требует отдельных критериев:** автопрокрутки и движущегося содержимого (2.2.2), мигания (2.3.1), содержимого, которое появляется только при наведении (1.4.13), форм (3.3.x к странице не относятся). Ориентация экрана не заблокирована (1.3.4).
- **Смена цен при переключении периода** не объявляется читалке. Это не нарушение: изменение запускает сам пользователь, и оно идёт сразу за переключателем. Если захочется, можно добавить скрытую строку с `aria-live="polite"` вида «Цены за 3 месяца».

## Вопросы к основателю

1. **Сравнение и тариф «Индивидуально» на узких экранах.** Две строки сравнения и список услуг Axiom убраны на телефоне сознательно. Но они пропадают и у тех, кто увеличил страницу на компьютере, а это нарушение 1.4.4 и 1.4.10. Как лучше: показать всё или спрятать под раскрывашку «Ещё 2 отличия» и «Что входит»?
2. **Меню на экранах уже 880 px.** Сейчас оно просто исчезает. Нужна ли компактная кнопка «Разделы», или достаточно прокрутки?
3. **Кнопки в ценах.** Что лучше: текст 19 px (вид почти не изменится) или чуть более тёмный оранжевый #cc4318 для мелких кнопок?
4. **Сноска про суммы.** Можно ли написать источник одной строкой прямо под цифрами «≈ $147K» и «≈ $95K» вместо звёздочки и сноски в подвале? Так не придётся прыгать в конец страницы и обратно.
5. **Английские названия листов** (Payments, Monthly spend, Insights) и пометки Review, DBL. Русский голос читалки прочтёт их с русским произношением. Как собственные названия они под требование 3.1.2 не попадают. Если важно, чтобы звучали правильно, их можно обернуть в `<span lang="en">`.
