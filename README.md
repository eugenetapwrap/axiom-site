# Сайт Axiom Consulting

Лендинг финансового консалтинга для девелоперов, генподрядчиков и инвесторов: финансовые модели, аудит моделей, учёт и контроль платежей, инвестиционный анализ.

Сделан на [Astro](https://astro.build): одна статическая страница, без фреймворков на клиенте.

## Как запустить

```bash
npm install
npm run dev      # локально на http://localhost:4321
npm run build    # сборка в папку dist/
```

Добавьте `?review` к адресу, чтобы подсветить факты, которые ждут подтверждения.

## Где что лежит

- `src/content/ru.ts` — все тексты страницы. Править тексты здесь. Факты на проверку помечены `tbd: true`.
- `src/components/` — секции страницы.
- `src/components/mock/` — макеты результатов работы (сводка модели, отчёт об аудите, дашборд) на вымышленных данных.
- `src/styles/global.css` — токены: цвета, шрифты, отступы. Описание ролей — в `DESIGN.md`.
- `src/lib/typo.ts` — типограф: неразрывные пробелы после предлогов и между числом и единицей.
- `docs/research/` — исследование, на котором построен сайт:
  - `00-materials.md` — факты из материалов Axiom;
  - `01-competitors-cis.md`, `02-competitors-international.md` — конкуренты;
  - `03-client-questions.md` — вопросы и страхи клиентов по сегментам;
  - `04-ux-evidence-and-design-refs.md` — UX-исследования и дизайн-референсы;
  - `05-current-site-audit.md` — почему не работала прошлая версия;
  - `06-positioning-and-structure.md` — позиционирование и структура страницы;
  - `07-to-confirm.md` — что подтвердить перед запуском.

## Правила

- Страница отвечает на вопросы клиента, а не рассказывает о нас.
- Метрики (NPV, IRR, BOQ) не выносим в заголовки, только в ответы.
- Не выдумываем цифры, отзывы и логотипы. Данные клиентов не показываем: все цифры в макетах вымышленные, а кейсы — только обезличенные и с согласия клиента.

## Публикация

Подключите репозиторий к Cloudflare Pages или Vercel: фреймворк Astro определится сам, каждый пуш в `main` будет публиковаться автоматически.
