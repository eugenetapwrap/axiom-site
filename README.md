# Сайт Axiom

Сайт финансовой команды Axiom (Бали): финмодели, аудит финмоделей, управленческий учёт, бот для чеков.

Сделан на [Astro](https://astro.build): статические страницы, без лишних скриптов.

## Как запустить

```bash
npm install
npm run dev      # локально на http://localhost:4321
npm run build    # сборка в папку dist/
```

## Где что лежит

- `src/data/home.ts` — все тексты главной. Править тексты здесь.
- `src/data/site.ts` — контакты и ссылки.
- `src/styles/global.css` — цвета, шрифт, сетка и отступы (переменные в `:root`).
- `src/lib/typo.ts` — типограф: неразрывные пробелы после предлогов и между числом и единицей.
- `src/pages/` — страницы (`index.astro` — главная, `404.astro`).

## Правила

Тексты по информационному стилю Ильяхова, вёрстка по правилам Бюро Горбунова:
факты вместо оценок, заголовки говорят суть, без метафор канала на главной и в услугах,
иерархия размером и воздухом, один акцентный цвет. Данные клиентов не показываем,
все скрины и цифры в макетах — вымышленные.

## Публикация

Проще всего подключить репозиторий к Vercel или Cloudflare Pages:
Import project → выбрать `axiom-site` → фреймворк Astro определится сам.
После этого каждый пуш в `main` публикуется автоматически.
