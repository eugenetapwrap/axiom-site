# Лендинг Nota — notagetbot.com

Отдельный сайт на [Astro](https://astro.build), одна страница на русском. Структура и тексты — `../founder/landing.md`, макет — холст «Nota, эскизы», страница «Лендинг».

## Запуск

```bash
cd nota
npm install
npm run dev      # http://localhost:4321
npm run build    # готовый сайт в nota/dist/
```

**Поисковики.** По умолчанию страница закрыта от индексации (`noindex`). В день запуска — только по команде основателя — задать на хостинге переменную `PUBLIC_INDEX=1` для Production и пересобрать; в Preview её не задавать. Перед этим: убрать черновики отзывов и жёлтые заглушки (`grep -c 'class="todo"' dist/index.html` → 0), выложить соглашение и политику, обновить `lastmod` в `public/sitemap.xml`.

## Где что

- `src/data/content.ts` — **все тексты**. Править здесь.
- `src/pages/index.astro` — порядок блоков.
- `src/styles/global.css` — цвета и шрифты (токены в `:root`).
- `src/components/MiniReport.astro` — упрощённая карточка отчёта на демо-данных. Заменить на скриншоты настоящих карточек, когда будут.
- `public/og.png` — картинка-превью, когда ссылку пересылают в Telegram.

Каждая кнопка ведёт в бота с меткой источника: `t.me/NotaGetBot?start=land_hero`, `land_offer`, `land_price_start` и т. д. Бот должен записывать этот параметр, чтобы было видно, какой блок приводит людей.

## Публикация на notagetbot.com

Сайт выложен 25.11.2026 на Cloudflare Pages.
- Проект **`nota`** в Cloudflare (Workers & Pages), подключён к GitHub-репозиторию `axiom-site`.
- Сборка идёт из ветки `claude/plugin-marketplace-founder-skill-dpl9t0`. **Каждый коммит в эту ветку сразу выкладывается на сайт.**
- Настройки сборки: Root directory `nota`, команда `npm run build && rm -rf dist/pay`, папка `dist`. Страница оплаты не выкладывается, пока нет сервера и банка: тогда убрать `&& rm -rf dist/pay` из команды.
- Домены `notagetbot.com` и `www.notagetbot.com` — CNAME на `nota-5cw.pages.dev` (через прокси Cloudflare). Почта на домене — записи Zoho (MX, SPF, DKIM), их не трогать.
- Поисковикам сайт закрыт (`noindex` на всех страницах). Чтобы открыть главную, в настройках проекта добавить переменную окружения `PUBLIC_INDEX=1` и пересобрать. Документы, `/archive/` и оплата останутся закрытыми.
- Переадресация с `notagetbot.app` на `notagetbot.com` пока не настроена.

## Скриншоты таблицы и аналитики

Лежат в `public/screens/`, показываются во вкладках блока «Таблица и аналитика». Тестовые данные.

| Файл | Лист |
|---|---|
| `payments.webp` | Payments |
| `monthly-spend.webp` | Monthly spend |
| `insights.webp` | Insights |

Чтобы заменить, положите файл с тем же именем и поправьте размеры `w` и `h` в `src/data/content.ts` (блок `analytics`). Если файла нет, на его месте будет заглушка.

## Две версии лендинга

- `/` — `src/pages/index.astro`, тексты в `src/data/content.ts`. Метки ссылок на бота `land_*`.
- `/v2/` — `src/pages/v2.astro`, отличия в `src/data/content-v2.ts`, общие блоки из `content.ts`. Первым идёт оффер «пришлите чеки за прошлый месяц — через 20 минут готовый учёт». Метки `land2_*`, страница закрыта от поисковиков (`noindex`).

- `/v3/` — `src/pages/v3.astro`, тексты в `src/data/content-v3.ts`. Заголовок про контроль, боль наверху, одни цифры (40 документов, около 20 минут), шаг с Google на виду, 9 блоков. Метки `land3_*`, `noindex`. Заглушки `⟦…⟧` подсвечиваются жёлтым — это места, где нужны факты (отзывы, ссылки на соглашение и политику).

- `/v4/` — `src/pages/v4.astro`, тексты в `src/data/content-v4.ts`. Объединение v2 и v3: оффер «архив → отчёт за 20 минут», «Что придёт», «Что Nota делает с каждым документом», группа — по желанию одной строкой, без полосы доверия. Метки `land4_*`, `noindex`.

- `/v5/` — `src/pages/v5.astro`, тексты в `src/data/content-v5.ts`. v4 + разбор «глазами клиента и маркетолога»: подсказка «как выгрузить архив» под кнопкой, сравнение «9:41» сразу после «Что придёт», четыре способа отправки как в v2, данные без упоминания моделей, цена за документ, отзывы скрыты. Метки `land5_*`, `noindex`.

- `/v6/` — `src/pages/v6.astro`, тексты в `src/data/content-v6.ts`. Костяк и порядок рассказа из v2, факты и правки из v3–v5. Метки `land6_*`, `noindex`.
- `/v7/` — `src/pages/v7.astro`, тексты в `src/data/content-v7.ts`. v6, прогнанная через скиллы (текст, утверждения, вёрстка, доступность, SEO); цены перед «Ваши данные» с переключателем «помесячно / за год». Метки `land7_*`, `noindex`, превью `public/og-v7.png`. Дизайн-система — `DESIGN.md`.
- `/v8/` — `src/pages/v8.astro`, тексты в `src/data/content-v8.ts`. Вариант «Итог» из v7 без переключателя: цифры шагов 1–4 (пунктир на компьютере), шаг 2 «Что покажет отчёт», подчёркнутые «20 минут». Метки `land8_*`, `noindex`. Дальше работаем с ней.
- `/v9/` — `src/pages/v9.astro`, тексты в `src/data/content-v9.ts`. v8 + новый первый экран (без карточек «От вас / От Nota», короткий подзаголовок, тёмно-синяя строка над заголовком, маленький QR) и скользящая картинка отчёта на компьютере (на телефоне: оффер → картинка → пункты отчёта). Технический переключатель сверху: первый экран и отчёт — «новый / как в v8». Метки `land9_*`, `noindex`.
- **Главная `/` = версия 10** — разметка `src/components/Landing.astro`, страница `src/pages/index.astro`, тексты `src/data/content-v10.ts`. Прежние версии v1–v9 перенесены в `src/pages/_archive/` (папки с «_» Astro не собирает, на сайт они не попадают; исходники сохранены). Описание v10: v9 без переключателя (скользящий отчёт по умолчанию) + ответы основателя по разбору шести проверяющих: подсказка про архив с телефона, на телефоне без цифр шагов и с закреплённой кнопкой, короткое сравнение на телефоне, общие пункты тарифов строкой, «Компания» вместо Developer, факты о документах, группах, данных и юрлице, исправленный пример отчёта (`archive-report-v10.webp`), QR `land10_qr`. Метки `land10_*`, `noindex`.

- **Главная `/` = версия 12, новый вариант** (с 25.11): `src/pages/index.astro`, тексты `src/data/content-v12.ts` поверх `content-v11.ts`, метки `land12s_*`. Вариант с архивом — `/archive/` (`src/pages/archive.astro`), метки `land12a_*`, `noindex`. Подробно — `founder/landing-v12-notes.md`.

Метки позволяют сравнить версии по тому, сколько людей запустили бота с каждой.
